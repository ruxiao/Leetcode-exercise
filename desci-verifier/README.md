# DeSci Verifier - MVP

This project is a Minimum Viable Product (MVP) for a DeSci (Decentralized Science) Verifier. 
Its primary goal is to verify the reproducibility of research code by:
1.  Cloning a Git repository.
2.  Building a Docker environment based on specified dependencies.
3.  Executing a defined script within the Docker container.
4.  Checking for expected output files.

This is the first phase of a larger initiative as detailed in the comprehensive DeSci Verifier design document.

## Prerequisites

*   **Git:** Must be installed and accessible in your PATH.
*   **Docker:** Must be installed, running, and accessible without `sudo` (or you'll need to run the CLI with `sudo`).
*   **Python 3.7+:** Required to run the `cli.py` script.

## How to Run

1.  **Clone this Repository (DeSci Verifier Tool):**
    ```bash
    git clone <URL_of_this_desci_verifier_tool_repo>
    cd desci-verifier 
    ```

2.  **Prepare a Configuration File:**
    *   Create a JSON configuration file that specifies the target repository and verification parameters.
    *   See `config_examples/cli_test_config.json` for an example.
    *   Key fields:
        *   `git_url`: URL of the research code repository to verify.
        *   `branch`: (Optional) Specific branch to use.
        *   `run_script`: Path to the script to execute (relative to the root of the target repo).
        *   `dependency_file`: Name of the dependency file (e.g., `requirements.txt`). Used if no custom `dockerfile` is provided.
        *   `dockerfile`: (Optional) Path to a custom Dockerfile in the target repo (relative to its root). If provided, this will be used instead of generating one.
        *   `expected_output_files`: A list of file paths (relative to the target repo root) expected to be generated by `run_script`.

3.  **Run the CLI Tool:**
    Execute the `cli.py` script, providing the path to your configuration file:
    ```bash
    python cli.py path/to/your_config.json
    ```
    For example, to run the test configuration provided:
    ```bash
    python cli.py config_examples/cli_test_config.json
    ```
    This example uses `https://github.com/ai-powered-dev/dummy-python-project.git`, which is a simple Python project designed for this test.

## Workflow

The `cli.py` script performs the following steps:

1.  **Parses Configuration:** Reads the provided JSON file.
2.  **Clones Repository:** Clones the target Git repository into a temporary local directory (`./temp_repo_clone_cli`).
3.  **Prepares Build Context:** Places the `desci_container_wrapper.py` (used for execution inside Docker) into the cloned repository.
4.  **Builds Docker Environment:**
    *   If a `dockerfile` is specified in the config and found in the target repo, it's used to build the Docker image.
    *   Otherwise, `src/environment_builder.py` generates a Dockerfile using `templates/Dockerfile.python.template` and the specified `dependency_file`. This generated Dockerfile also includes the `desci_container_wrapper.py`.
    *   A Docker image is built from the target repository context.
5.  **Executes Code:**
    *   The `src/code_executor.py` runs the specified `run_script` inside a new container based on the built image.
    *   It uses `desci_container_wrapper.py` to manage the execution, capture stdout/stderr/exit_code, and check for `expected_output_files`.
6.  **Reports Results:** Prints the exit code, stdout, stderr of the script, and the status of expected output files.
7.  **Cleans Up:** Removes the temporary cloned repository. The Docker image remains for inspection (manual removal if desired).
